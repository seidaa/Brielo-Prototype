## Naming system

Apply this naming system consistently across the whole app:

- **Brio** = app name
- **Move / Moves** = one-time activities
- **Make a Move** = create a new activity
- **Join the Move** / **I’m In** = join an activity
- **What’s the Move?** = core discovery/home framing
- **Live Moves Nearby** = nearby real-time activity section
- **Move Chat** = temporary chat for a specific activity
- **After the Move?** = post-activity follow-up prompt
- **Crews** = recurring activity groups
- **Sessions** = structured activity formats like gym, study, coworking, gaming, creative, or skill-based meetups
- **Movement** = broader brand philosophy only, not a user-created object

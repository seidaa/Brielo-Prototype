2. Add Leave Move option

If a user has already joined a Move, show a clear secondary option on the Move Detail screen:

“Leave Move”

Placement:

* Below the primary “Open Move Chat” button
    OR
* In a subtle secondary button near the bottom
    OR
* In a small options/menu area

Behavior:
When user taps “Leave Move,” show a confirmation modal:

Title:
“Leave this Move?”

Copy:
“You’ll be removed from the attendee list and the Move Chat will disappear from your chats.”

Buttons:

* Cancel
* Leave Move

After confirming:

* Remove the user from the Move attendee count
* Change the Move CTA back to “I’m In” or “Ask to Join”
* Remove the Move from the user’s active Moves
* Remove that Move Chat from the Move Chats list
* Update chat unread badge/count if needed
* Save the updated state in localStorage
* Show a small confirmation toast:
    “You left the Move.”

Important:
If the user is hosting the Move, do not show “Leave Move.”
For hosted Moves, show a separate option:
“Cancel Move”
but it can be non-functional or show a placeholder confirmation for now.

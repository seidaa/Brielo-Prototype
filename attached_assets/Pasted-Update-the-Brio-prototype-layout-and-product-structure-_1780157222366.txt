Update the Brio prototype layout and product structure.

This is a layout redesign + rebrand refinement, not a full rebuild.

Keep:
- React + Tailwind
- localStorage/mock data
- existing clickable prototype behavior
- dark/light/auto theme system
- no backend
- no WebSockets
- no push notifications
- no payments
- no real auth

New app identity:
Brio is a social lifestyle app for making real-life moves, joining recurring circles, and doing more outside the screen.

Core language:
- Brio = app name
- Moves = one-time activities
- Make a Move = create an activity
- Circles = recurring activity groups
- Sessions = structured activities like gym/study/work/creative meetups
- Live Moves Nearby = active nearby activities
- After the Move? = follow-up prompt
- Brio Livestreams = future feature only, do not fully build yet

Important:
I want the layout to feel different from the old Rally prototype.
Make Brio feel warmer, more lifestyle-focused, more social, and less like a generic event listing app.

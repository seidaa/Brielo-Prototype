CLEANUP GOALS

1. Verify Show-Up Trust language

Search user-facing UI and docs for banned or outdated warning labels.

Do not use:

* Low Show-Up Rate
* Low Show Rate
* Flake
* Bad User
* Creepy
* Bad Reviews
* Blacklisted
* Unreliable

Use:

* Show-Up Rate only as a stat/metric
* Recently Missed Moves as the warning label
* Shows Up
* Reliable
* Good Vibes
* Trusted Host
* Would Move Again
* New / Limited History
* Host Review Recommended

Correct examples:

* Show-Up Rate: 92%
* Jordan K. · 68% show-up rate · Recently Missed Moves

Incorrect examples:

* Low Show-Up Rate
* Low Show Rate
* Flake warning

2. Verify trust copy tone

Make sure the trust system feels firm but fair.

Keep copy aligned with:
“Your spot matters.”
“Leaving early is better than no-showing.”
“If you join a Move, you’re holding a spot someone else may have wanted.”
“Recent behavior matters most. Show up consistently to improve your trust status.”

Avoid public shaming or harsh punishment language.

3. Verify Join flow

Test or inspect the I’m In flow.

Expected behavior:

* Tapping I’m In opens the “Save your spot?” commitment modal.
* Modal explains limited spots and that someone else may want the spot.
* Confirming joins the Move.
* Attendee count updates.
* Move Chat appears for the joined Move.
* Toast or confirmation copy appears.

Make sure this does not break Move cards, Move Detail, Discover, or localStorage.

4. Verify Leave Move flow

Expected behavior:

* Joined Moves show Leave Move.
* Leave Move opens confirmation copy:
    “Leaving early is better than no-showing. We’ll free your spot so someone else can join.”
* Confirming Leave Move removes the user from the Move.
* Attendee count updates.
* Move Chat disappears from chat list.
* Leaving a Move does NOT count as a no-show.
* Toast/copy says:
    “You left the Move. Your spot is open again.”

5. Verify post-Move feedback fairness

Check the feedback system for reversible logic.

Important:
Any toggleable trust feedback must be symmetric:

* selecting “Didn’t Show” applies the missed Move impact
* unselecting “Didn’t Show” reverses that impact
* selecting “Would Move Again” increases that count
* unselecting it reverses that count
* selecting “Good Vibes” increases that count
* unselecting it reverses that count

Do not allow repeated toggling to stack penalties or inflate positive stats.

6. Verify Profile Trust section

Profile should include a Trust section showing:

* Trust Status
* Show-Up Rate
* Moves Attended
* Missed Moves
* Would Move Again
* Good Vibes
* “Your spot matters” copy
* “How trust works” modal/link

Make sure this section does not feel too crowded or overly punitive.

7. Verify Move Detail trust display

* Host trust context should appear subtly.

* Warning labels should be visible but not huge or shame-y.
* Move Detail should still show Move info, time/location, spots, vibe tags, Who’s In, After the Move?, Report Move, and Move Chat access.

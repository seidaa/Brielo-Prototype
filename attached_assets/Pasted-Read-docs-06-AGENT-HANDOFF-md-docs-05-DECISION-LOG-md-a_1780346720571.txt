11. Preserve fairness

Rules:

* One missed Move should not permanently damage a user.
* Leaving a Move before it starts should not count as a no-show.
* Negative feedback should not be publicly displayed as reviews.
* Reports and Felt Off signals should feel private/safety-oriented.
* Warnings should be based on repeated behavior, not one-off mistakes.
* Use “Recently Missed Moves” for warning language, not “Low Show-Up Rate.”

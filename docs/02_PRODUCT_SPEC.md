# Brielo Product Spec

## Product Summary

Brielo is a mobile social lifestyle app that helps people make real-life Moves, meet people through activities, and add good people to their Circle.

Brielo is not:

* a dating app
* a professional networking app
* just an event listing app
* just a nightlife app
* a recurring club app by default

## Core Insight

People do not just need more events. They need help turning social intent into real-life action and finding people they would actually do things with again.

## Product Language

* Moves = one-time activities users create or join
* Make a Move = create an activity
* Make It Live = submit/create a Move
* I'm In = join a Move
* Leave Move = leave a Move and remove its chat
* Move Chat = temporary chat for a joined Move
* Circle = people the user has moved with and would move with again
* Add to Circle = add someone after a Move
* In Your Circle = already added
* Circle Activity = updates from people the user has moved with before
* Live Moves Nearby = active nearby Moves
* Live Map = map view of nearby Moves
* After the Move? = post-Move reactions, feedback, Would Move Again, and Add to Circle
* Sessions = structured activities like gym, study, work, gaming, creative, or skill-based meetups
* Brielo Livestreams = future feature only, not MVP core

## Important Circle Clarification

Circles are people-based, not recurring themed groups by default.

A Circle is a lightweight social graph made from people the user met through Moves and would move with again.

Do not treat Circles as:

* recurring clubs by default
* themed community groups by default
* Meetup-style groups by default
* Crews

## Current Prototype Status

* Built in Replit
* Mobile-first React/Tailwind-style prototype
* Uses localStorage/mock data
* Buttons are clickable
* Posting a Move works
* Created Moves appear in the app
* No real backend yet
* No real authentication
* No payments
* No WebSockets
* No push notifications
* No real livestreaming
* No production database yet

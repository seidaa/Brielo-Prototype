## Product Summary

Brielo is a mobile social lifestyle app that helps people make real-life Moves, meet people through activities, and add good people to their Circle.

## Brand Stack

* App name: Brielo
* Pronunciation: BREE-loh
* Primary tagline: Live More
* Core action phrase: Make a Move
* Secondary marketing line: Less scrolling. More doing.
* Supporting line: Find people to do things with — once, weekly, or whenever you're down.

## Product Language

* Moves = one-time activities users create or join
* Make a Move = create an activity
* Make It Live = submit/create a Move
* I'm In = join a Move
* Leave Move = leave a Move and remove its chat
* Move Chat = temporary chat for a joined Move
* Circle = people the user has moved with and would move with again
* Add to Circle = add someone after a Move
* In Your Circle = already added
* Circle Activity = updates from people the user has moved with before
* Live Moves Nearby = active nearby Moves
* Live Map = map view of live nearby Moves
* After the Move? = post-Move prompt for reactions, attendee feedback, Would Move Again, and Add to Circle
* Sessions = structured activities like gym, study, work, gaming, creative, or skill-based meetups
* Brielo Livestreams = future feature only, not MVP core
